# Integrated Systems Hydrology Lab - GitHub Pages site

This is a static, accessible GitHub Pages version of the Integrated Systems Hydrology Lab website.

## Publish on GitHub Pages

1. Create a GitHub repository, for example `integrated-systems-hydrology`.
2. Upload every file in this folder to the repository root.
3. In GitHub, go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

For a user/organization site at `https://YOUR-USERNAME.github.io/`, name the repository `YOUR-USERNAME.github.io` and upload these files to the root.

## Accessibility features included

- Semantic landmarks: header, nav, main, sections, footer
- Skip link to main content
- Visible keyboard focus states
- High-contrast text and links
- Responsive layout without requiring JavaScript
- `aria-current` on active navigation links
- Reduced-motion support
- Descriptive link text

## Images

Google Sites embedded images were not copied into this package. Add exported image files to an `assets/` folder and replace the profile/project placeholders with real `img` tags, including meaningful `alt` text.
