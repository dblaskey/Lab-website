# Integrated Systems Hydrology Lab - GitHub Pages site

This is a static, accessible GitHub Pages version of the Integrated Systems Hydrology Lab website.

## Accessibility features included

- Semantic landmarks: header, nav, main, sections, footer
- Skip link to main content
- Visible keyboard focus states
- High-contrast text and links
- Responsive layout without requiring JavaScript
- `aria-current` on active navigation links
- Reduced-motion support
- Descriptive link text
